---
title: "Backup &amp; Restore Windows 10 Activation"
date: 2012-06-28
categories: 
  - "technical"
---

Copy the file activation token file from the activated Windows 10.

```
Location : C:\ProgramData\Microsoft\Windows\ClipSVC\token.dat
```

Try to do the backup & restore from booting into another OS or recovery mode.
