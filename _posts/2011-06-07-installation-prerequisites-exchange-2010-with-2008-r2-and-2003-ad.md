**Installation prerequisites Exchange 2010 with 2008 R2 and 2003 AD.**

1\. .Net Framework 3.5.

2\. 2007 Office System Converter.

3\. Raise Domain Functional Level of "Active Directory Users and Computers" & "Active Directory Domains and Trusts" to "Windows Server 2003".

4\. Add windows 2008 R2 Server to AD.

5\. Login as domain administrator and start the installation.
