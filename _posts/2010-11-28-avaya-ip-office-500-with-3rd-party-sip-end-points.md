Today I'm going to discuss about 3rd party sip end point registration with Avaya IP Office 500 v2 PBX. You have to have a "3rd Party IP Endpoints" license in order to do this configuration. [![](/images/license.png "License")](/images/license.png)

Create a new user and an extension in Avaya as shown in screen shots below. [![](/images/user_1.png "Create User")](/images/user_1.png)

On the same user menu under Telephony Supervisor Settings enter the Login Code. This will be the actual SIP password. [![](/images/user_2.png "Telephony")](/images/user_2.png)

On the Extension menu make sure corresponding extension is created. [![](/images/user_3.png "Extension")](/images/user_3.png)

If not create a new SIP extension by right clicking the Extension menu. [![](/images/user_4.png "New Extension")](/images/user_4.png)
