**Enable Remote Linux Syslog Server**

**Syslog Client configuration** Edit /etc/syslog.conf @192.168.1.40

```bash
service syslog reload
```

Here 192.168.1.40 is remote syslog server.

**Syslog Server configuration**

edit  /etc/sysconfig/syslog

add -r in SYSLOGD OPTIONS

```ini
SYSLOGD_OPTIONS="-m 0 -r"
```

```bash
/etc/init.d/syslog restart
```
